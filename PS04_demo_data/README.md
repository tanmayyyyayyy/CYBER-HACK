# PS04 Demo Dataset — ATM CCTV Suspect Face Extraction

**Rajasthan Police Hackathon 2026 (RPH26) · Problem Statement PS04**

This folder contains reference files, format samples, and the builder script that lets
any team create their own structured demo dataset from self-filmed ATM-style videos.

---

## Folder map

| Path | Contents |
|---|---|
| `_tools/build_ps04.py` | Dataset builder script — `init` + `build` commands |
| `raw_videos/` | **Put your video clips here** |
| `clip_manifest.csv` | Generated by `init`; fill in before `build` |
| `00_format_samples/` | Reference files: EJ sample, evidence sheet template, video format guide, consent form, bank statement sample, manifest template |
| `01_reference/atm_master.csv` | 6 demo ATMs with DVR export profiles, clock offsets |
| `02_videos/` | *(generated)* Re-encoded clips per ATM + format-coverage copies + proprietary stub |
| `03_transactions/` | *(generated)* EJ journal + bank statement per ATM |
| `04_cases/` | *(generated)* Case brief per primary person |
| `99_answer_key/` | *(generated)* Judges-only answer key CSV |

---

## Quick start

```bash
# 1. Place your videos in raw_videos/
# 2. Generate & fill the manifest
python3 PS04_demo_data/_tools/build_ps04.py init PS04_demo_data/
# edit PS04_demo_data/clip_manifest.csv
# 3. Build
python3 PS04_demo_data/_tools/build_ps04.py build PS04_demo_data/
```

See `HOW_TO_USE_YOUR_VIDEOS.md` for the full walkthrough.

## Difficulty matrix

| Feature | ATMs | What tools are tested on |
|---|---|---|
| Clean H.264 baseline | JPR0142 | basic decode, face extraction |
| Old DVR, large MJPEG AVI | JPR0317 | container handling, AVI indexing |
| H.265/HEVC | AJM0055 | HEVC codec support |
| QuickTime .mov | JDH0208 | MOV container |
| Low-bitrate WMV | KOT0091 | compression artefact handling |
| CIF night IR + raw .264 stream | UDR0019 | worst-case quality, raw stream ingestion |
| Dahua .dav stub | UDR0019 | proprietary format detection + graceful error |
| Clock offset up to 1 hour | all | time-window alignment |

## Terms of use

- Dataset videos are **for hackathon judging only** — do not publish publicly.
- Transactions are **entirely fictional** — no real card or account data.
- Delete all recordings within the number of days stated on the volunteer consent forms.
- Do not match faces against Aadhaar, criminal databases, or any government system.
