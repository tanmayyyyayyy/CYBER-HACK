# Authority Response Desk demo

Open **Response desk** in the main navigation. This is a local presentation screen inside the existing prototype.

## Suggested walkthrough

1. Show the yellow simulation banner and explain that the ATM-04 event is fictional; no responder is contacted.
2. Select **Acknowledge & take ownership**, add a short note, then demonstrate **Request more information**, **Escalate for review**, or **Resolve**. These actions only update browser-local demo state.
3. Open **Handoff packet**. Load the synthetic demo case first if no analysis is listed. Select an analysis to preview its case reference, clip hash, review counts, and audit context. Download the JSON or print the preview.
4. Open **Activity timeline** and compare actual local application audit entries with the simulated response actions. Explain that neither view alone establishes independently protected legal chain of custody.
5. Use **Reset demo** to restore the fictional alert to its initial state before another presentation.

The handoff includes metadata only; it does not attach the source video or face images. Review the preview before downloading or printing, especially if the local workspace contains any non-demo information. Do not present a downloaded packet as an official report.
